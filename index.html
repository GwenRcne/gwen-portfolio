Projets représentatifs du BTS SIO

Gestion automatisée des utilisateurs — PowerShell, Python & SQL

Résumé : Ce projet automatise la gestion des comptes MariaDB en extrayant les données d'Active Directory via PowerShell. Python assure la normalisation des identifiants et le hachage sécurisé des mots de passe par l'algorithme bcrypt. L'outil finalise l'administration via des scripts SQL automatiques et une interface graphique intuitive.

Compétences : Réseau, DHCP, DNS, Sécurisation

Architecture Haute Disponibilité — Docker & HAProxy

Résumé : Mise en place d'une infrastructure web robuste et évolutive utilisant Docker. L'architecture intègre la répartition de charge via HAProxy entre plusieurs serveurs web PHP, ainsi qu'un système de gestion de base de données MariaDB.

Compétences : Docker, HAProxy, MariaDB, Réseaux

Site vitrine — HTML/CSS

Résumé : Création d'un site web.

Compétences : HTML, CSS, Hébergement

Mise à jour GLPI 10.0.14 → 10.0.22

Résumé : Mise à jour sécurisée de GLPI sur un serveur Debian, avec sauvegarde préalable de la base MariaDB et des fichiers, migration du schéma de données, puis vérification du bon fonctionnement avant remise en production.

Compétences : Administration Linux, Sauvegarde, Bases de données, Sécurisation

Gestion des admins locaux — PowerShell & Microsoft Intune

Résumé : Script PowerShell déployé via Intune retirant les comptes non autorisés du groupe Administrateurs locaux et ne conservant que les accès essentiels (LAPS, Domain Admins, compte brise-glace).

Compétences : PowerShell, Microsoft Intune, Sécurisation, Active Directory

Redéploiement de HP Support Assistant — Microsoft Intune

Résumé : Reconstruction du package d'installation (.intunewin) et reconfiguration de l'application dans Intune pour corriger un dysfonctionnement, validée par des tests sur postes pilotes.

Compétences : Microsoft Intune, Packaging, Déploiement, Tests

Script de désinstallation de HP Support Assistant — Scripting

Résumé : Script automatisant la désinstallation complète de HP Support Assistant, facilitant la maintenance et la réinstallation sur les postes concernés.

Compétences : Scripting, Maintenance, Automatisation

Migration de serveur Debian 10 vers Debian 13

Résumé : Migration complète d'un serveur Plesk obsolète vers une nouvelle VM Debian 13, avec sauvegarde, configuration, et transfert des données via Plesk Migrator, finalisée par une bascule d'IP sans interruption de service.

Compétences : Virtualisation, Linux, Plesk, Migration de données, Continuité de service
